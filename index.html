Duratus Backups

Duratus Backups is a private administrative utility used to save and restore encrypted backups of the Duratus website. It is operated by the Duratus backup administrator. It is not a member registration or payment application.

An authorized administrator connects a Google Drive account. The utility writes encrypted backup files to its dedicated backup folder and reads those files when checking or restoring a backup. It requests access only to specific Drive files used with the app. It does not request access to all files in the connected Drive.

The utility has no public account-registration process. Contact: frankkepler@gmail.com.
