Privacy information

Duratus Backups uses Google's drive.file permission to create and manage its own backup folders and files. Its Drive access includes file metadata needed to locate backup objects and encrypted file contents needed to upload, verify and restore backups. It does not request access to unrelated Drive files, Gmail, contacts or calendars.

Website backups can contain membership registrations, dependent records, waivers, website content and server configuration. Backup contents are encrypted before they are uploaded to Drive. The encryption password is stored separately from the Drive backup files. Google account authorization credentials are stored privately on the replacement server and the administrator's recovery device so that the backup utility can access its backup objects.

The utility uses this information only for backup administration, integrity checking and restoration. It does not use it for advertising, profiling or model training. Backup objects are stored in the Google Drive account selected by the administrator. Access through Drive also depends on that account's sharing settings; backup folders should remain private.

The administrator controls backup retention and deletion. No automatic deletion schedule is currently enabled for this new repository. Revoking the app's connection in Google Account settings stops future app access; revocation does not itself delete existing encrypted backup files. Existing backup files can be managed by the Drive account owner. Loss of the separate encryption password prevents recovery of encrypted backup contents.

Contact the backup administrator at frankkepler@gmail.com for questions about this utility or its backup records. This page must be reviewed and updated if the utility's data practices change.
